# agent —— 页面级科研 Agent

当前有两个明确分工的只读 Agent，共享同一套项目证据与作用域：

1. **项目悬浮助手**（`assistant.py`）
   - 技能矩阵：`agent_skills.py`
   - 受限上下文：`context.py`
   - 固定只读工具：`tools.py`
   - 需确认的草稿写工具：`write_tools.py`
   - 回答项目现状、文献比较、证据缺口、方案推进、实验状态、复现完整度和页面操作。
2. **论文阅读助手**（`extract.py` / `guide.py`）
   - 抽取原文条目并校验逐字引文；
   - 生成有出处、分层的阅读导览；
   - 分析关键假设、参数口径、局限、复现所需与相关文献。

共同边界：

- 项目作用域由 Python 会话上下文决定，模型不能覆盖；
- 模型不能执行 SQL、shell、Python、文件路径或 DOM；
- 对话和 AI 解释不写进原文证据；
- 唯一写工具只能修改现有计划草稿的文本字段，生成建议不落库，必须用户确认后才应用；
- 不自动运行实验，不提供删除数据或任意数据库写入；
- 只读工具结果有行数和字符上限，并记录调用日志。

更上层的科研协作与计划建议仍由 `chat.py` / `plan_draft.py` 的受限角色处理，
它们的建议必须经用户确认后才能进入草稿或版本。
