# AI 解读三模式契约

三种模式分别服务“筛选文献 → 准备复现 → 深度精读”。它们共享证据真实、页码可定位、
不编造论文事实的底线，但不得共享同一套输出结构。

## 模式总表

| 模式 ID | 界面名称 | 场景 | 核心结构 | 篇幅 | 页码 |
|---|---|---|---|---|---|
| `quick` | 精简摘要版 | 30 秒判断是否继续读 | 单段：主题 + 结论 + 方法标签 | 不设字数限制 | 仅末尾统一页码范围 |
| `audit` | 方法重点版 | 准备复现和提取方法流程 | 目标 + 步骤 + 参数 + 边界 | 不设字数限制 | 每步绑定页码 |
| `deep` | 标准详细版 | 完整精读和沉淀研究笔记 | 固定七维 | 不设字数限制 | 关键结论绑定页码与引文 |

## 精简摘要版

目标：帮助读者在 30 秒内决定“是否值得继续读”。

输出必须：

- 是一个连贯自然段；
- 包含核心主题、核心结论和方法标签；
- 只做价值与相关性判断；
- 末尾由程序统一添加页码范围。

禁止：

- 分段标题或项目符号；
- 公式、参数值、单位、具体处理步骤；
- 正文中的逐页页码角标；
- 大段研究背景；
- 把方法重点版或标准详细版删句后放进 `quick.text`。

篇幅由内容决定，不设字数限制。

正例结构：

```text
这是一篇研究什么问题、采用哪些方法标签的论文。它的核心结论是……。
该结论适用于……，主要边界是……。若你的目标是……，值得继续读；否则……
```

## 方法重点版

目标：让读者能按步骤准备复现，并把步骤直接映射到复现方案。

固定结构：

```json
{
  "mode": "audit",
  "audit": {
    "core_goal": "一句话说明复现目标",
    "steps": [
      {
        "order": 1,
        "title": "步骤名",
        "purpose": "为什么做",
        "input": "输入",
        "method": "操作和判断逻辑",
        "output": "输出",
        "params": [
          {"name": "参数", "value": "取值", "unit": "单位", "note": "说明"}
        ],
        "metric": "评价指标",
        "risk": "失败条件或风险",
        "evidence": [{"text": "依据", "quote": "逐字原文"}]
      }
    ],
    "boundaries": ["适用条件", "不能外推的情形"]
  }
}
```

约束：

- 不设字数限制；
- 至少 70% 内容用于方法、输入输出、参数和适用边界；
- 每一步必须有一条逐字原文证据，最终页码由程序定位；
- 弱化背景、贡献综述和研究展望；
- 参数值、单位和处理顺序必须与原文一致。

## 标准详细版

目标：完成沉浸式精读，重建论文的问题、方法、假设、数据、结果和边界。

固定七维：

1. 研究背景；
2. 核心方法；
3. 理论假设；
4. 实验数据；
5. 结果发现；
6. 局限争议；
7. 研究展望。

每一维必须包含：

- 具体 `summary`；
- 2–5 条具体 `points`；
- 1–2 条逐字 `evidence`。

约束：

- 不设字数限制；
- 不得删减维度；
- 不得把方法重点版步骤直接拼成七维；
- 关键结论必须能回到原文引文和页码；
- 作者自承局限、AI 识别的问题和未验证争议要分清。

## 差异化自检

- [ ] 当前输出是否只用了本模式允许的字段？
- [ ] 精简版是否完全没有参数值和步骤？
- [ ] 方法版是否超过 70% 篇幅在讲方法与边界？
- [ ] 标准版是否覆盖全部七维且不只是长摘要？
- [ ] 是否只是从另一模式缩句或扩句得到？
- [ ] 页码粒度是否符合当前模式？
- [ ] 所有正式引文是否已在本地原文定位？
