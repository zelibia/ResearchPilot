# 单篇论文解读模板

> 本模板只用于“标准详细版”。精简摘要版和方法重点版必须使用
> `reading-modes.md` 的单段/复现结构，不能把本模板删减后复用。

复制下面骨架逐项填写。没有证据的条目写「论文未提供」或「当前无法核实」，
**不留空、不编造**。方括号里是填写要求，不是要保留的占位文字。

```markdown
# [论文标题]

## 身份（已核验）
- 作者：[以 Crossref/OpenAlex 为准；与 PDF 内嵌值不同时并列并注明来源]
- 年份 / 期刊：[同上]
- DOI：[规范化后的小写形式]
- 版本：[期刊版 / arXiv 版本号；两者都有时都写]
- 研究主题：[一句话]
- 身份核验：[已核验（来源）｜存在冲突：本地 x vs 外部 y｜未能核实]

## 阅读问题
- Q1：[这次精读必须回答的问题]　状态：已回答 / 部分回答 / 当前无法回答
- Q2：[…]
- Q3：[…]

## 1 研究问题（原文依据）
- [问题陈述]　→ 原文依据：第 N 页「逐字引文」
- 既有方法的限制：[同上]

## 2 研究贡献
- 作者声称：[贡献]　→ 原文依据：第 N 页「逐字引文」
- AI 判断：[哪些主张有证据、哪些只有主张]　（标注为 AI 解释）

## 3 理论基础
- 核心假设：[…]　→ 第 N 页「逐字引文」
- 关键公式：[…]　→ 第 N 页「逐字引文」
- 适用条件：[…]　（AI 解释，依据：上面第 N 页）
- 背景补充：[…]　→ 来源：[文献标题 / DOI / 学科常识]

## 术语与符号
| 术语/符号 | 原文定义或上下文 | 解释 | 来源 | 状态 |
|---|---|---|---|---|
| [term] | [第 N 页「逐字引文」] | [AI 解释，依据 evidence ID] | [论文 / 外部 DOI / 无] | 论文明确 / 外部支持 / 推断 / 待核实 |

## 4 方法流程
1. [步骤]　→ 第 N 页「逐字引文」
2. [步骤]　→ 第 M 页「逐字引文」
- 步骤间因果：[…]　（AI 解释）

## 5 关键参数
| 参数 | 值（逐字） | 出处 | 论文是否说明选择理由 |
|---|---|---|---|
| [名] | [值] | 第 N 页 | 有：[引文]／未说明理由 |

## 6 结果解释
- 报告结果：[…]　→ 第 N 页「逐字引文」
- 评价标准 / 基准：[…]　→ 第 N 页
- 未报告的内容：[…]（不要推断补齐）

## 7 局限与争议
- 作者承认：[…]　→ 第 N 页「逐字引文」
- 可识别的潜在问题：[…]　（待核实：说明推理链与需要什么证据）

## 8 可复现清单
- 数据要求：[…]／论文未提供
- 环境与工具：[…]／论文未提供
- 关键参数：[见上表]
- 算法步骤：[见方法流程]
- 评价指标：[…]／论文未提供
- 尚缺信息：[逐条列出]

## 9 延伸文献
- 理论基础：[标题 / 作者 / 年份 / DOI / 核验状态 / 为什么相关]
- 方法来源：…
- 应用案例：…
- 改进与争议：…

## 10 覆盖度与过程
- 覆盖：读了 X/Y 页、Z 个章节块；失败 n 次请求（原因）
- 丢弃：有 k 条引文在原文定位不到，按"不作为依据"处理
- 锚点：原文命中状态 exact / partial / none / no_text_layer / out_of_range 各多少条
- 标注：方法/结论/疑问/局限的分类数量；颜色只表示类别，不表示置信度
- 思考过程：[单独折叠区，过程性内容，不作为证据]

## 四层标注检查
- [ ] 每条结论都能归到：原文依据 / AI 解释 / 背景补充 / 待核实
- [ ] 页码与引文真实可定位
- [ ] 相关文献都带核验状态
- [ ] 没有把建议值写成实测值
```
